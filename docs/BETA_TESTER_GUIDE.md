# Bank of Dad - Beta Tester Guide

## Thank you for testing

Thank you for trying Bank of Dad with your family. This beta is about learning what works in a real home, what children enjoy and what parents need before the product is polished further.

## What Bank of Dad is

Bank of Dad is a family chore and pocket-money reward system. Children complete chores, parents approve them, and the child earns pocket money, XP, streaks, badges and progress towards rewards.

It is not a real bank and does not connect to real bank accounts.

## What to test

Please try the app as part of your normal family routine.

Test these areas:

- Add or select a child account
- View available chores
- Mark chores complete
- Approve or reject chores
- Check XP, level and badges
- Use the reward shop
- Add a kindness or no-reminder bonus
- Add a streak day
- Apply interest
- Open Dad Editor mode
- Edit chore names and values
- Edit reward shop items
- Edit child balances and savings goals

## Suggested testing period

Use the app for 1-4 weeks.

A few days will show whether the app is understandable. A few weeks will show whether it becomes part of the family routine.

## Parent feedback questions

1. Was it easy to understand?
2. Did your child understand what to do?
3. Did the approval queue feel useful?
4. Did the reward values feel fair?
5. Did XP, badges and streaks help motivation?
6. Did your child care about the prize shop?
7. What did you need that was missing?
8. What was confusing?
9. Would this reduce arguments about pocket money?
10. Would you recommend it to another parent?

## Child feedback questions

Ask your child:

1. Did you like using it?
2. What was your favourite part?
3. Did you like earning XP and badges?
4. Did you like saving towards a reward?
5. What reward would you add to the shop?
6. What badge would you like to unlock?
7. Was anything confusing?
8. Would you use it again?

## Bugs to report

Please report anything that feels broken, including:

- Buttons not working
- Money not updating correctly
- Chores disappearing
- Children disappearing
- Badges not unlocking
- Reward purchases not working
- Data resetting unexpectedly
- Layout problems on phones or tablets

## Useful details when reporting a bug

Please include:

- Device type
- Browser
- What you clicked
- What you expected
- What actually happened
- Screenshot if possible

## Things to remember

The current version stores data in the browser. Clearing browser data may remove the saved family data.

The current version is a working beta, not a finished public product.

## Best type of feedback

The most useful feedback is honest and practical.

Examples:

- My child did not understand this button.
- I wanted a PIN before editor mode.
- The reward shop needs pictures.
- I would use this if it worked on my phone home screen.
- I need weekly chores, not just one-off chores.

## Beta tester mission

Use Bank of Dad as if it was already part of your family routine and tell us what would make you keep using it.
