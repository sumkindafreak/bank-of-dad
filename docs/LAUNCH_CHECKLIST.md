# Bank of Dad - Launch Checklist

## Repository polish

- README explains the product clearly.
- Documentation folder exists.
- Marketing copy exists.
- Press kit exists.
- Roadmap exists.
- Beta tester guide exists.
- Feature audit exists.
- PNG social card exists.
- Asset folder explains which images to use.

## Visual assets

- Social card PNG added.
- SVG source files kept for editable artwork.
- README uses the PNG because it is easier to preview.
- Future asset exports are listed.

## Before sharing publicly

- Check the README on GitHub.
- Confirm the PNG image loads.
- Open the live app and take screenshots.
- Add screenshots to the asset folder later.
- Record a short demo video.
- Prepare a beta signup form.

## First social launch

- Post founder story.
- Share the social card.
- Ask for beta testers.
- Link to the GitHub repository if useful.
- Ask parents what features they would want.

## First beta test

- Invite 10 to 20 families.
- Ask them to use it for at least one week.
- Collect parent feedback.
- Collect child feedback.
- Prioritise the next build based on real usage.

## Best next feature after launch docs

Parent PIN protection should be the first serious product feature because it protects editor mode, approvals and balance changes.
