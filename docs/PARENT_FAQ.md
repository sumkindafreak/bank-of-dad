# Bank of Dad - Parent FAQ

## Is Bank of Dad a real bank?

No. Bank of Dad is a household reward tracker for chores, pocket money and saving goals. It does not connect to real bank accounts and does not move real money.

## Who controls the money values?

Parents or guardians control the chore values, balances, rewards and approval decisions.

## Can children award themselves money?

The current app uses a parent approval queue. Children can submit a chore, but the reward is only added when it is approved.

## Where is the data stored?

The current web version stores data locally in the browser using localStorage.

## What happens if browser data is cleared?

The saved family data may be removed. A future export and backup feature is recommended.

## Is there a parent PIN?

Not yet. Parent PIN protection is one of the recommended first future features.

## Is there a child PIN?

Not yet. Child PIN or avatar login is listed as a future enhancement.

## Can I edit chores?

Yes. Dad Editor mode allows chores, rewards and child account details to be edited.

## Can I add custom rewards?

Yes. The reward shop can be edited in Dad Editor mode.

## Can it work on a phone?

The web app can be opened in a browser. A future PWA install mode is recommended so it can behave more like an app.

## Can it sync between devices?

Not currently. The present version is local-first. Cloud or local network sync could be explored later.

## What age is it for?

It is best suited to families where children are old enough to understand chores, rewards and saving goals. Parents can adjust chores and rewards to suit their household.

## What makes it different from a normal chore chart?

Bank of Dad combines chores, parent approval, pocket-money tracking, XP, levels, badges, streaks, savings goals and a reward shop in one retro-style system.

## What is the physical terminal idea?

The long-term idea is to run Bank of Dad on an ESP32-S3 touchscreen so families can have a dedicated home reward terminal.
