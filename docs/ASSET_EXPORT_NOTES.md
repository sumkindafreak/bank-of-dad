# Bank of Dad - Asset Export Notes

## Why PNG files were added

Some devices and apps do not open SVG files easily. SVG files are useful as editable vector artwork, but PNG files are easier to preview, share and upload to social media.

## Current image status

The asset folder now includes:

- `bank-of-dad-social-card.png` - standard shareable PNG image
- `logo.svg` - editable vector logo card
- `social-card.svg` - editable vector social card
- `feature-map.svg` - editable vector feature map

## Recommended workflow

Use PNG files for:

- Facebook posts
- GitHub README preview images
- Press images
- Social sharing
- Sending to people on phones

Use SVG files for:

- Editing
- Scaling without quality loss
- Future exports
- Design source files
