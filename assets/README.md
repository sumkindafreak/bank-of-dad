# Bank of Dad - Asset Pack

This folder contains visual assets for Bank of Dad marketing and documentation.

## Openable image files

- `bank-of-dad-social-card.png` - standard PNG social image for Facebook, GitHub previews, posts and press use.

## Vector source files

These files are SVG vector graphics. Some apps do not open SVG files directly, but they are useful for editing, scaling and future design work.

- `logo.svg`
- `social-card.svg`
- `feature-map.svg`

## Recommended use

Use the PNG file when sharing online or opening on a phone or computer.

Use the SVG files when editing the design or creating new sizes.
